Nova UI

Abrir proposta →
Roteiro rápido (5–8 min):
  1. Painel / Visão Geral — primeiros números que você vê
  2. Funil — clique num card e abra o drawer
  3. Sinais — grade de leitura
  4. Configurações → Minha conta / Preferências
  5. Entregas e Funcionários (opcional)

Perguntas para o feedback

  • A proposta fica mais clara / mais fácil de usar que a atual?
  • O menu em cima (em vez da sidebar) ajuda ou atrapalha?
  • Os gráficos na Visão Geral ajudam a decidir, ou poluem?
  • No drawer da proposta: tirar e-mail / pesquisar / Prob. / Fechamento (ficar só Follow-up) faz sentido?
  • O que você não mudaria de jeito nenhum?
